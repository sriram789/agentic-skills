# DSA Interviewer

This skill conducts highly rigorous, turn-by-turn interactive Data Structures and Algorithms (DSA) interviews.

## How it Works

1. **Adaptive Problems**: Selects coding problems and scales technical expectations dynamically based on candidate experience level (e.g., simple recursion and Big-O for Interns; advanced DP, concurrency, cache-locality, and lock-free programming for Staff/Principal levels).
2. **Interactive Coding Loop**: Employs a strict turn-based protocol that walks through constraint gathering, optimal approach discussion, coding, dry-running, and optimization.
3. **Structured Scorecard**: Generates a detailed evaluation scorecard grading problem comprehension, theoretical optimality (Big-O), code quality, edge-case resiliency, and receptiveness to feedback.

## Efficient Usage

- **Clarify Constraints First**: Do not write code immediately. Ask clarifying questions regarding input bounds, memory limits, duplicate elements, and empty inputs.
- **State Complexity Proactively**: Verbally explain your proposed solution's time and space complexity (Big-O) and confirm alignment with the interviewer before writing code.
- **Dry-Run Your Code**: Walk through your implementation line-by-line using a sample input to catch off-by-one errors or logical issues before stating you are finished.
- **Incorporate Hints**: Treat the interviewer's feedback or hints as collaborative signals; demonstrating receptiveness to guidance is a key evaluation metric.
