# ATS-Optimized Resume Builder

This skill builds and rewrites resumes optimized for Applicant Tracking Systems (ATS) and hiring managers, focusing on senior and lead engineering roles at big tech companies.

## How it Works

1. **Document Analysis**: Parses your self-assessments, performance reviews, previous resumes, and project write-ups to extract roles, achievements, and technical keywords.
2. **Target Alignment**: Gathers your target job descriptions and companies to dynamically adjust keyword strategies (e.g., highlighting "scalability" for Google or "ownership" for Amazon).
3. **Keyword Strategy**: Generates a custom keyword map ensuring critical domain terms appear in context within bullet points, not just in a lists section.
4. **Bullet Point Transformation**: Rewrites accomplishment descriptions using the high-impact formula: `[Strong verb] + [what you did] + [scale/context] + [quantified result]`.
5. **Layout Structuring**: Outlines a clean, single-column, standard-section layout to maximize ATS parser accuracy.

## Efficient Usage

- **Provide a Job Description**: Pasting the target job description is the single highest-leverage input for keyword optimization.
- **Provide Raw Accomplishments**: Paste raw text from performance reviews or project notes without worrying about formatting; the builder is designed to extract, refine, and polish.
- **Review Quantified Metrics**: For every role, verify that each bullet contains at least one metric (users, QPS, time, team size, percentages). If you do not have exact numbers, use informed estimates (e.g., "~2M daily").
- **Maintain Layout Simplicity**: Avoid adding multi-columns, tables, graphics, or custom headers/footers to the generated output, as these can disrupt ATS parsers.
